# FastPvP — Fabric 1.21.1

Client-side Crystal PvP helper:

- Right-click an End Crystal with an End Crystal in hand -> attacks/breaks it.
- Right-click an anchor with Glowstone -> charges it to 4 charges in one click.
- Right-click a full anchor -> explodes it, even while holding Glowstone.
- Intended for fast Crystal/Anchor PvP.

## Build

Requires Java 21 and Gradle/Fabric Loom. Run:

Windows:
`gradlew.bat build`

Linux/macOS:
`./gradlew build`

The compiled mod will be in `build/libs/`.

Target: Minecraft 1.21.1, Fabric.
